# 🔍 cybernestsec — محاكاة توعية بمخاطر مشاركة الصور

> **⚠️ تنبيه:** هذا المشروع مخصص للتعليم والتوعية الأمنية حصراً. جميع الأشخاص والأسماء والصور في المنشورات خيالية أو مُولَّدة، ولا يُجمع أو يُرسل أي شيء إلى أي خادم — كل شيء يعمل محلياً داخل المتصفح.

---

## 📌 نظرة عامة

**cybernestsec** هي صفحة ويب تفاعلية تُحاكي فيد منصة تواصل اجتماعي (بأسلوب إنستغرام)، مصممة لبيئات التدريب والتوعية في مجال الأمن السيبراني وخصوصية المعلومات (OSINT).

تحتوي منشورات الحساب التجريبي على تفاصيل بصرية صغيرة تبدو عادية للوهلة الأولى — تصريح موقف سيارات، بطاقة اسم في مناسبة، ملاحظة لاصقة على المكتب، شهادة تخرج، بطاقة دخول فندق، وغيرها. هذه التفاصيل يمكن لمراقب دقيق استخدامها لاستنتاج الاسم الحقيقي لصاحب الحساب، جامعته أو جهة عمله، عنوان سكنه، روتينه اليومي، أو حتى خطط سفره.

تُستخدم هذه المحاكاة في ورش العمل التدريبية لإيصال رسالة واحدة: **الصور "العادية" التي ننشرها يومياً قد تكشف عنا أكثر مما نتخيل.**

---

## 🎯 الأهداف التعليمية

- توعية المستخدمين بأن التفاصيل الخلفية في الصور (لافتات، ملصقات، شاشات، مستندات) قد تُشكّل بصمة رقمية كاملة
- تدريب المشاركين على "قراءة" الصورة كما يقرأها محقق OSINT، لا كمشاهد عادي
- إظهار كيف يمكن ربط تفاصيل متفرقة من عدة منشورات ببعضها (مثل شعار حقيبة يتكرر، أو ملصق نفس الجامعة) للوصول إلى استنتاج أدق
- تعزيز عادة مراجعة الصورة كاملة قبل نشرها، لا التركيز على الشخص فقط

## ✨ المميزات

| الميزة | التفاصيل |
|---|---|
| 🖼️ فيد بأسلوب إنستغرام | منشورات، تعليقات، وسوم (هاشتاغات)، وموقع لكل منشور |
| ❤️ تفاعلات كاملة | إعجاب، حفظ، تعليق، متابعة — من جهة المتصفح فقط، لا تُحفظ بعد إعادة التحميل |
| 🔎 عارض صور (Lightbox) | تكبير بالتمرير أو النقر المزدوج، وسحب للتنقل داخل الصورة المكبّرة |
| ⌨️ تحكم بلوحة المفاتيح | الأسهم للتنقل بين الصور، ومفتاح `Esc` للإغلاق |
| 🔔 لوحة إشعارات ونوافذ ملف شخصي | محاكاة تفاعلية للعناصر المحيطة بالفيد الحقيقي |
| 🕵️ وضع المحقق (Investigator Mode) | يُفعَّل بالضغط على مفتاح **`I`** — يُظهر علامات حمراء مرقّمة فوق كل صورة، مع تلميح يشرح كل تسريب معلومات عند تمرير الفأرة |
| 🔍 بحث فوري | تصفية المنشورات حسب النص، الوسوم، أو الموقع |
| 📱 تصميم متجاوب | الشريط الجانبي يتقلص على الأجهزة اللوحية، وعرض بعمود واحد على الجوال |
| 🔒 خصوصية كاملة | لا يوجد اتصال بأي خادم خارجي، ولا يُطلب أي إذن من المتصفح (لا كاميرا، لا موقع جغرافي، لا شيء) |

## 🚀 طريقة الاستخدام

لا يحتاج المشروع إلى أي تثبيت أو بناء (build) أو خادم خلفي:

```bash
# الخيار 1: افتح الملف مباشرة في أي متصفح
open index.html

# الخيار 2: أو شغّله محلياً (مفضّل لتفادي قيود الوصول للملفات)
python3 -m http.server 8000
# ثم افتح المتصفح على http://localhost:8000
```

أو استضفه على أي منصة استضافة ثابتة:
- [GitHub Pages](https://pages.github.com/)
- [Netlify](https://netlify.com/)
- [Vercel](https://vercel.com/)

---

## 🕵️ استخدام وضع المحقق

1. افتح الموقع.
2. اضغط على مفتاح **`I`** في لوحة المفاتيح.
3. ستظهر علامات حمراء مرقّمة فوق كل صورة — مرّر الفأرة فوق أي علامة لمعرفة التفصيل الذي تكشفه وسبب أهميته.
4. اضغط **`I`** مجدداً لإيقاف الوضع.

---

## 🧪 سيناريو الاستخدام في ورش العمل

1. **المُيسِّر** يعرض الفيد أمام الحضور كصفحة إنستغرام عادية، دون تفعيل وضع المحقق
2. **المشاركون** يُطلب منهم محاولة استنتاج أكبر قدر من المعلومات عن صاحبة الحساب بأنفسهم أولاً
3. **المُيسِّر** يُفعّل وضع المحقق (`I`) لمقارنة ملاحظات المشاركين بالتفاصيل الفعلية المخفية في كل صورة
4. **النقاش:** يُربط كل تسريب بمخاطره الواقعية (تحديد الموقع، الهندسة الاجتماعية، انتحال الهوية، إلخ)

## 🛠️ التقنيات المستخدمة

- **HTML5 / CSS3 / JavaScript خام (Vanilla)** — بدون أي إطار عمل أو مكتبات خارجية أو أدوات بناء
- بدون أي واجهات برمجية حساسة (لا `getUserMedia`، لا `geolocation`، لا `Battery API`)
